# agenticlakehouse.com

Plain static HTML. Netlify publishes the repo root as committed; there is no build step.

Before every commit that adds or changes pages:

```sh
node scripts/apply-network.mjs   # network head (GA4, Person JSON-LD, twitter:site), CTA strip, footer
git commit ...                    # commit page content first
python3 apply_dates.py            # dateModified/datePublished in JSON-LD, from git history
python3 build_sitemap.py          # sitemap.xml with git-derived lastmod
python3 build_llms.py             # llms.txt
git commit -m "[mechanical] Refresh dates, sitemap, llms.txt"
```

- `network/` is generated by `alexmercedcom/scripts/build-network-shared.mjs`. Never edit it by hand.
- Dates come from `page_dates.py`: the last commit that changed a page's content. Commits whose subject contains `[mechanical]` (or that only touch the footer, nav, or WebMCP loader) are skipped, so tag chrome-only commits with `[mechanical]`.
- Redirects live in `_redirects`. `data/crosslinks.json` maps builder pages here to the matching leader pages on agenticanalyticsnow.com; the same table is copied to that repo.
